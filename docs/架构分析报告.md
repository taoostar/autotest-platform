## 2. Agent 与用例执行完整流程

```
┌─────────────────────────────────────────────────────────────────────┐
│                        完整执行流程                                  │
└─────────────────────────────────────────────────────────────────────┘

1. 用户操作 (前端)
   └── Tasks 页面 → 创建任务 → 分发任务

2. 后端处理 (backend/app/routes/tasks.py)
   ├── create_task()       创建 TestTask (status=pending)
   └── dispatch_task()
       ├── 查询 TestPlan 的用例列表
       ├── 为每个用例创建 TaskResult
       ├── 通过 SocketIO 向 Agent 发送 task_assign 事件
       └── 更新 Task status = running

3. Agent 接收 (agent/agent.py)
   └── AgentNamespace.on_task_assign()
       ├── 发送 task_ack 确认
       └── 启动新线程执行 _execute_task()

4. Agent 执行用例 (agent/executor.py)
   ├── Executor.execute()
   │   ├── 创建临时脚本文件
   │   ├── subprocess.Popen() 启动子进程
   │   ├── select.select() 实时读取 stdout/stderr
   │   ├── log_callback 实时推送日志
   │   ├── process.wait() 回收子进程
   │   └── 返回 ExecutionResult
   └── PerformanceCollector 采集性能数据 (CPU/内存/IO)

5. Agent 上报结果
   └── sio.emit('task_complete', {...})

6. 后端更新 (backend/app/agents/websocket_events.py)
   └── handle_task_complete()
       ├── 更新 TaskResult 状态
       ├── 检查是否全部完成 → 更新 Task 状态
       └── 推送 task_update 到前端

7. 前端实时更新 (frontend/src/services/socket.js)
   └── TaskDetail 页面显示日志/性能/结果
```

## 4. WebSocket 双命名空间

| 命名空间 | 方向 | 主要事件 |
|---------|------|---------|
| `/ws/agent` | Server → Agent | `task_assign`, `task_cancel` |
| `/ws/agent` | Agent → Server | `task_complete`, `log`, `performance`, `heartbeat` |
| `/ws/client` | Client → Server | `subscribe_task` |
| `/ws/client` | Server → Client | `task_log`, `task_update`, `performance` |

### 4.1 Agent 命名空间事件详情

**Agent → Server 事件:**
- `register` - Agent 注册 (hostname, os_type, labels)
- `heartbeat` - 心跳 (status, load)
- `task_ack` - 任务接收确认
- `task_complete` - 任务执行结果
- `task_cancelled` - 取消确认
- `log` - 实时脚本输出
- `performance` - 性能数据

**Server → Agent 事件:**
- `connected` - 连接确认
- `task_assign` - 分配新任务
- `task_cancel` - 取消任务
- `heartbeat_ack` - 心跳确认

## 5. Executor 脚本执行 (agent/executor.py)

### 5.1 支持的脚本类型

```python
EXECUTORS = {
    'python': ['python3', '{script}'],
    'python3': ['python3', '{script}'],
    'shell': ['bash', '{script}'],
    'bash': ['bash', '{script}'],
    'javascript': ['node', '{script}'],
    'js': ['node', '{script}'],
}
```

### 5.2 执行流程

```python
def execute(script_content, script_type, timeout, env_vars, log_callback):
    # 1. 写临时脚本文件
    with tempfile.NamedTemporaryFile(suffix=...) as f:
        f.write(script_content)
        script_path = f.name

    # 2. 构建命令并执行
    with self._lock:
        self.process = subprocess.Popen(cmd, stdout=PIPE, stderr=PIPE)
        process = self.process

    # 3. 实时读取输出
    while True:
        reads = [process.stdout, process.stderr]
        ret = select.select(reads, [], [], 0.1)
        # 读取并推送日志...

    # 4. 等待进程结束并回收
    process.wait()
    exit_code = process.returncode

    # 5. 返回结果
    return ExecutionResult(exit_code, stdout, stderr, duration)
```

### 5.3 线程安全机制

- `threading.Lock()` 保护 `self.process` 共享状态
- 局部变量 `process` 保存引用，避免并发覆盖
- `cancel()` 方法通过锁安全终止当前进程
- `finally` 块清理 `self.process = None`

## 6. Agent 配置 (agent/config.yaml)

```yaml
agent_id: 1              # Agent 唯一标识
platform_url: http://localhost:5000  # 后端地址
heartbeat_interval: 30   # 心跳间隔(秒)
performance_interval: 5  # 性能采集间隔(秒)
labels: []               # 标签(用于分发策略)
```

### 6.1 Agent 启动流程

```
1. Load config from config.yaml
2. Connect to platform WebSocket with ?token={agent_id}
3. On connect -> emit 'register' -> receive 'connected'
4. Start heartbeat thread (every 30s)
5. Wait for 'task_assign' event
6. On task_assign:
   a. Emit 'task_ack'
   b. Start executor thread
   c. collector.start(task_id, perf_callback)
   d. executor.execute(script, type, timeout, env_vars, log_callback)
   e. On complete -> emit 'task_complete' with results
   f. collector.stop()
7. On 'task_cancel' -> executor.cancel()
```
