# AutoTest Platform 测试用例设计文档

## 一、测试策略概述

### 1.1 测试分层

```
┌─────────────────────────────────────────────────────────┐
│                    E2E 测试 (Playwright)                  │
│         端到端用户场景验证，覆盖核心业务流程               │
└─────────────────────────────────────────────────────────┘
                            ▲
                            │
┌─────────────────────────────────────────────────────────┐
│                 集成测试 (Pytest)                        │
│     API 接口测试、服务间交互、数据库操作、WebSocket        │
└─────────────────────────────────────────────────────────┘
                            ▲
                            │
┌─────────────────────────────────────────────────────────┐
│                 单元测试 (Pytest + Jest)                 │
│           业务逻辑、工具函数、React组件渲染               │
└─────────────────────────────────────────────────────────┘
```

### 1.2 测试框架

| 测试类型 | 框架 | 位置 |
|---------|------|------|
| 后端单元/集成测试 | pytest | `backend/tests/` |
| 后端 API 测试 | pytest + Flask test client | `backend/tests/` |
| 前端组件测试 | Jest / React Testing Library | `frontend/src/` |
| E2E 测试 | Playwright | `e2e/` |

```python
def test_concurrent_execution():
    """测试并发执行不会产生僵尸进程"""
    import threading
    import time

    executor = Executor()
    results = []
    errors = []

    def run_script(name):
        try:
            script = f'''
print("{name} starting")
import time
time.sleep(0.5)
print("{name} done")
'''
            result = executor.execute(script, 'python', 10, {})
            results.append((name, result.exit_code))
        except Exception as e:
            errors.append((name, str(e)))

    threads = [
        threading.Thread(target=run_script, args=(f'thread_{i}',))
        for i in range(3)
    ]

    for t in threads:
        t.start()

    for t in threads:
        t.join()

    # 验证无错误
    assert len(errors) == 0
    # 验证所有线程都完成
    assert len(results) == 3
    # 验证无僵尸进程
    # (通过 ps 检查，预期无 defunct 进程)
```

```python
        db.session.flush()

        plan = TestPlan(project_id=project.id, name='ParPerfPlan', collect_performance=True)
        db.session.add(plan)
        db.session.flush()

        agent = Agent(name='ParPerfAgent', status='online')
        db.session.add(agent)
        db.session.commit()

        # 创建并发任务
        task = TestTask(plan_id=plan.id, agent_id=agent.id, concurrency=3)
        db.session.add(task)
        db.session.commit()
        task_id = task.id

    # 分发任务
    response = client.post(f'/api/v1/tasks/{task_id}/dispatch', headers=auth_headers)
    assert response.status_code == 200

    # 验证无性能数据写入 (因为是并行模式)
    with app.app_context():
        perf_count = PerformanceLog.query.filter_by(task_id=task_id).count()
        assert perf_count == 0  # 并行执行不采集
```
