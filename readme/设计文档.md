# 第一章：平台概述

## 1.1 项目背景与目标

本项目旨在构建一个企业级自动化测试平台，支持多种类型的自动化测试（单元测试、API测试、UI测试、集成测试、性能测试、E2E），为QA工程师提供完整的测试管理、执行、报告能力。

**核心目标：**
- 统一管理测试用例、测试计划、测试任务
- 支持多用户、多团队、多项目隔离
- 提供实时日志和执行结果查看
- 支持定时任务和外部Webhook触发
- 提供历史趋势分析和报告导出

## 1.2 用户角色

| 角色 | 描述 | 权限 |
|-----|------|-----|
| QA工程师 | 平台主要使用者 | 全部功能（无权限管理需求，所有用户等价于管理员） |

**说明：** 所有用户均为管理员级别，无普通用户/管理员区分。

## 1.3 核心功能模块（按优先级排序）

| 优先级 | 模块名称 | 功能描述 |
|:------:|---------|---------|
| P0 | 测试用例管理 | 用例的增删改查、分类、标签、收藏、版本管理、在线编辑 |
| P0 | 测试任务管理 | 创建任务、指定Agent执行、查看实时日志、历史结果 |
| P1 | 测试计划管理 | 将多个用例组合成计划、设置执行参数、调度配置 |
| P1 | Agent管理 | Agent注册、状态监控、分组管理 |
| P2 | 报告中心 | 趋势分析、执行统计、导出HTML/PDF报告 |
| P2 | 定时任务管理 | Cron表达式调度、启用/禁用控制 |
| P3 | Webhook管理 | 外部系统触发、Token认证 |
| P3 | 系统设置 | 系统配置、审计日志查看 |
| P4 | 环境变量管理 | 全局/项目级环境变量配置 |

## 1.4 技术栈

| 层级 | 技术选型 | 说明 |
|-----|---------|------|
| 前端框架 | React 18 | SPA应用 |
| UI组件库 | Ant Design 5 | 企业级React组件库 |
| 代码编辑器 | Monaco Editor | VS Code同款编辑器 |
| 图表库 | ECharts | 趋势图、性能图表 |
| 后端框架 | Python Flask | RESTful API |
| 数据库 | PostgreSQL | 主数据存储 |
| 任务队列 | Redis + Redis Queue | 任务队列管理 |
| 实时通信 | Flask-SocketIO | WebSocket通信 |
| 性能采集 | Agent内置 + node_exporter | 双重采集能力 |

## 1.5 部署方式

- **部署模式**：单机/本地部署
- **多环境支持**：平台可在多个环境中部署，支持配置迁移
- **自动化脚本**：提供启动、停止、健康检查自动化脚本

## 4.1 接口规范

### 4.1.1 基础规范

- **协议**: HTTP/HTTPS
- **数据格式**: JSON
- **字符编码**: UTF-8
- **认证方式**: Session + Cookie (JWT Token)
- **API版本**: URL前缀 `/api/v1/`

### 4.1.2 通用请求头

```
Content-Type: application/json
Cookie: session_token=xxx
```

### 4.1.3 通用响应格式

**成功响应**:
```json
{
  "code": 0,
  "message": "success",
  "data": { ... }
}
```

**错误响应**:
```json
{
  "code": 1001,
  "message": "error description",
  "data": null
}
```

### 4.1.4 错误码定义

| 错误码 | 说明 |
|-------|------|
| 0 | 成功 |
| 1001 | 参数错误 |
| 1002 | 认证失败 |
| 1003 | 权限不足 |
| 1004 | 资源不存在 |
| 1005 | 资源已存在 |
| 1006 | 操作失败 |
| 1007 | 任务执行中 |
| 1008 | 超过限制 |

## 6.2 通信协议

### 6.2.1 连接建立

1. Agent启动时，从配置文件读取`platform_url`和`agent_token`
2. 建立WebSocket长连接: `ws://platform/ws/agent?token={agent_token}`
3. 连接成功后发送注册消息:

```json
{
  "type": "register",
  "hostname": "linux-server-01",
  "ip_address": "192.168.1.100",
  "os_type": "linux",
  "labels": ["linux", "staging"],
  "version": "1.0.0"
}
```

4. 接收平台注册响应:

```json
{
  "type": "register_ack",
  "agent_id": 1,
  "status": "registered"
}
```

### 6.2.2 心跳机制

- 间隔: 30秒
- 超时: 平台超过90秒未收到心跳则认为Agent离线
- 心跳内容:

```json
{
  "type": "heartbeat",
  "status": "idle|running",
  "load": 0.35,
  "current_task_id": null
}
```

### 6.2.3 任务执行流程

1. **接收任务**:
```json
{
  "type": "task_assign",
  "task_id": "xxx",
  "result_id": 1,
  "case_id": 100,
  "case_name": "test_login.py",
  "script_content": "#!/usr/bin/env python\n...",
  "script_type": "python",
  "env_vars": {"ENV": "staging", "DEBUG": "true"},
  "timeout": 300,
  "retry": 1
}
```

2. **发送ACK**:
```json
{
  "type": "task_ack",
  "task_id": "xxx",
  "result_id": 1,
  "status": "accepted"
}
```

3. **执行脚本** (伪代码):
```python
# 1. 创建临时目录
work_dir = /tmp/agent/{task_id}
os.makedirs(work_dir, exist_ok=True)

# 2. 写入脚本文件
script_file = os.path.join(work_dir, case_name)
with open(script_file, 'w') as f:
    f.write(script_content)

# 3. 准备环境变量
env = os.environ.copy()
env.update(env_vars)

# 4. 执行脚本
if script_type == 'python':
    cmd = ['python3', script_file]
elif script_type == 'shell':
    cmd = ['bash', script_file]
elif script_type == 'javascript':
    cmd = ['node', script_file]

# 5. 设置超时
result = subprocess.run(
    cmd,
    cwd=work_dir,
    env=env,
    timeout=timeout,
    capture_output=True,
    text=True
)

# 6. 解析结果
status = 'passed' if result.returncode == 0 else 'failed'
```

4. **发送结果**:
```json
{
  "type": "task_complete",
  "task_id": "xxx",
  "result_id": 1,
  "status": "passed|failed",
  "exit_code": 0,
  "duration": 12.5,
  "summary": "1 passed",
  "error_type": "AssertionError",      // 仅失败时
  "error_message": "Expected 200",       // 仅失败时
  "stack_trace": "...",                   // 仅失败时
  "screenshots": ["base64..."]           // 仅UI测试失败时
}
```

### 6.2.4 任务取消流程

1. 平台发送取消消息:
```json
{
  "type": "task_cancel",
  "task_id": "xxx"
}
```

2. Agent收到后:
   - 发送 SIGTERM (优雅停止)
   - 等待进程退出 (最多10秒)
   - 如果超时，发送 SIGKILL (强制终止)
   - 上报取消结果

3. 上报结果:
```json
{
  "type": "task_complete",
  "task_id": "xxx",
  "result_id": 1,
  "status": "cancelled",
  "duration": 5.2
}
```

## 6.3 性能监控

### 6.3.1 采集指标

| 指标 | 说明 | 采集方式 |
|-----|------|---------|
| cpu_percent | CPU使用率(%) | psutil.cpu_percent() |
| memory_percent | 内存使用率(%) | psutil.virtual_memory().percent |
| io_wait | IO等待(%) | psutil.cpu_times().iowait |
| fd_count | 文件描述符数量 | len(psutil.Process().open_files()) |

### 6.3.2 采集频率

- 每5秒采集一次
- 批量上报 (每30秒或积累100条)

### 6.3.3 上报格式

```json
{
  "type": "performance",
  "task_id": "xxx",          // 可选，当前执行的任务ID
  "cpu": 45.2,
  "memory": 62.1,
  "io_wait": 5.3,
  "fd_count": 128,
  "timestamp": "2026-04-04T10:30:10Z"
}
```

### 8.3.2 stop.sh

```bash
#!/bin/bash

SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
PROJECT_DIR="$(dirname "$SCRIPT_DIR")"
PIDS_DIR="$PROJECT_DIR/.pids"

echo "Stopping AutoTest Platform..."

# 停止前端
if [ -f "$PIDS_DIR/frontend.pid" ]; then
    FRONTEND_PID=$(cat "$PIDS_DIR/frontend.pid")
    if kill -0 $FRONTEND_PID 2>/dev/null; then
        kill $FRONTEND_PID
        echo "Frontend stopped (PID: $FRONTEND_PID)"
    fi
    rm "$PIDS_DIR/frontend.pid"
fi

# 停止后端
if [ -f "$PIDS_DIR/backend.pid" ]; then
    BACKEND_PID=$(cat "$PIDS_DIR/backend.pid")
    if kill -0 $BACKEND_PID 2>/dev/null; then
        kill $BACKEND_PID
        echo "Backend stopped (PID: $BACKEND_PID)"
    fi
    rm "$PIDS_DIR/backend.pid"
fi

# 优雅停止所有相关进程
pkill -f "python3 run.py" 2>/dev/null || true
pkill -f "vite" 2>/dev/null || true

echo "AutoTest Platform stopped"
```

### 8.4.2 init_data.py

```python
#!/usr/bin/env python3
"""初始化示例数据"""

import sys
sys.path.insert(0, 'backend')

from app import create_app, db
from app.models import User, Team, Project, Module, Agent, SystemConfig
from werkzeug.security import generate_password_hash

def init_sample_data():
    app = create_app()
    with app.app_context():
        # 创建管理员账号
        if not User.query.filter_by(username='admin').first():
            admin = User(
                username='admin',
                password=generate_password_hash('admin123')
            )
            db.session.add(admin)
            print("Created admin user")

        # 创建示例团队
        if not Team.query.filter_by(name='QA团队').first():
            team = Team(name='QA团队', description='QA团队')
            db.session.add(team)
            db.session.flush()

            # 创建示例项目
            project = Project(
                team_id=team.id,
                name='示例项目',
                description='这是一个示例项目'
            )
            db.session.add(project)
            db.session.flush()

            # 创建示例模块
            modules = [
                Module(project_id=project.id, name='API测试', description='API接口测试'),
                Module(project_id=project.id, name='Web UI测试', description='Web界面测试'),
                Module(project_id=project.id, name='Shell脚本', description='系统脚本测试'),
            ]
            for m in modules:
                db.session.add(m)
            print("Created sample project and modules")

        # 创建示例Agent
        if not Agent.query.filter_by(name='Demo-Agent').first():
            agent = Agent(
                name='Demo-Agent',
                hostname='demo-server',
                ip_address='127.0.0.1',
                os_type='linux',
                status='offline',
                labels=['demo', 'linux']
            )
            db.session.add(agent)
            print("Created demo agent")

        # 初始化系统配置
        configs = [
            ('log.max_size_mb', '10', '单任务日志最大大小(MB)'),
            ('log.retention_days', '30', '日志保留天数'),
            ('task.default_timeout', '300', '默认超时时间(秒)'),
            ('task.default_retry', '0', '默认重试次数'),
            ('upload.max_case_size_kb', '1024', '单个用例文件最大(KB)'),
            ('upload.max_zip_size_mb', '50', '批量上传ZIP最大(MB)'),
            ('agent.heartbeat_interval', '30', 'Agent心跳间隔(秒)'),
            ('agent.offline_threshold', '90', 'Agent离线阈值(秒)'),
        ]
        for key, value, desc in configs:
            if not SystemConfig.query.filter_by(key=key).first():
                config = SystemConfig(key=key, value=value, description=desc)
                db.session.add(config)
        print("Initialized system configs")

        db.session.commit()
        print("Sample data initialized successfully")

if __name__ == '__main__':
    init_sample_data()
```

## 附录B：Cron表达式说明

```
┌───────────── 分钟 (0-59)
│ ┌─────────── 小时 (0-23)
│ │ ┌───────── 日 (1-31)
│ │ │ ┌─────── 月 (1-12)
│ │ │ │ ┌───── 星期 (0-6, 0=周日)
│ │ │ │ │
* * * * *
```

**常用示例**:
- `0 9 * * *` - 每天9:00执行
- `0 9 * * 1-5` - 工作日9:00执行
- `0 2 * * 0` - 每周日2:00执行
- `*/15 * * * *` - 每15分钟执行

## 附录D：版本命名规范

采用语义化版本 (SemVer):
- **major**: 主版本号，不兼容的重大变更
- **minor**: 次版本号，兼容性的功能新增
- **patch**: 修订号，兼容性的问题修复

**示例**: 1.2.3
- 1: 主版本
- 2: 次版本
- 3: 修订号
